# E-commerce

Aplikasi e-commerce yang dibangun dengan Next.js, React, TypeScript, dan Tailwind CSS.

## Development

Jalankan server development dengan `npm run dev`, lalu buka [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — jalankan server development.
- `npm run build` — buat build production.
- `npm run start` — jalankan build production.
- `npm run lint` — jalankan ESLint.
